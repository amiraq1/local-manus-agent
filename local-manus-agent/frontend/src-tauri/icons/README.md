# App Icons

Place your app icons here:
- `32x32.png` - 32x32 pixels
- `128x128.png` - 128x128 pixels
- `128x128@2x.png` - 256x256 pixels
- `icon.icns` - macOS icon
- `icon.ico` - Windows icon

Generate icons from a source image using:
```bash
npx @aspect-build/tauri-icon-gen icon-source.png
```

Or use the Tauri CLI:
```bash
npx tauri icon icon-source.png
```
