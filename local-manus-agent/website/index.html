Local Manus Agent

Local autonomous AI agent inspired by Manus, powered by local models. Plan, code, review, and verify — all on your machine.

GitHub Download v1.0.0 Quick Start

Features

Everything you need for autonomous local development

🧠

Multi-Agent

6 specialized agents coordinated by an orchestrator: Planner, Coder, Reviewer, Security, Browser, Memory.

🤖

Local LLM

Ollama with qwen2.5-coder:7b. No cloud APIs, no data leaves your machine. LiteRT-LM ready.

🐳

Docker Sandbox

Commands run in isolated containers. Non-root, no network, memory limited, timeout enforced.

🌐

Browser Automation

Headless Chromium verifies output visually. Screenshots, element checks, JS evaluation.

🧠

Memory / RAG

File indexing, keyword search, context retrieval. The agent remembers decisions and project structure.

📱

Termux Support

Runs on Android via Termux with automatic platform detection and security adaptations.

📲

PWA

Installable as a web app on mobile. Responsive UI with bottom navigation for small screens.

🔒

Security Hardened

Permission system, audit trail, blocked patterns, Safe Mode with approval flow.

Architecture

Multi-agent pipeline with specialized roles

MemoryAgent→ PlannerAgent→ SecurityAgent→ CoderAgent→ ReviewerAgent→ BrowserAgent

Quick Start

Up and running in 3 commands

git clone https://github.com/amiraq1/local-manus-agent.git
cd local-manus-agent
python scripts/setup.py
python scripts/start.py

# Open http://localhost:3000

Android / Termux

Full support on mobile with Termux Lite Mode

pkg update && pkg install python nodejs git
git clone https://github.com/amiraq1/local-manus-agent
cd local-manus-agent
./setup-termux.sh && ./start-termux.sh
